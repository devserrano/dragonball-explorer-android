# Dragon Ball Explorer

Aplicación Android desarrollada en Kotlin que consume la Dragon Ball API utilizando Retrofit.

## Características

- Login y Registro con Firebase Authentication
- Consumo de API REST
- RecyclerView para mostrar personajes
- Búsqueda dinámica por nombre
- Pantalla de detalle
- Navegación entre actividades
- Carga de imágenes con Glide

## Tecnologías

- Kotlin
- Android Studio
- Firebase Authentication
- Retrofit
- Glide
- RecyclerView
- XML Layouts

## Estructura del Proyecto

- LoginActivity
- RegisterActivity
- MainActivity
- CharacterDetailActivity

## API Utilizada

https://dragonball-api.com
